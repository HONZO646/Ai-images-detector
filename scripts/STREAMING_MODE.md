# 🚀 Streaming Mode - Обучение без загрузки данных на диск

## Что это?

**Streaming mode** позволяет обучать модель **без скачивания всего датасета** на диск. Данные подгружаются из HuggingFace по мере необходимости, batch за batch'ом.

## Преимущества

✅ **Экономия диска** — не нужно 10-20 GB для ImageNet-1k  
✅ **Быстрый старт** — не нужно ждать загрузки всех данных  
✅ **Автоматическое кэширование** — часто используемые данные кэшируются  
✅ **Меньше IO** — нет операций сохранения/чтения с диска  

## Как использовать

### По умолчанию (Streaming ON)

```python
# config.py
@dataclass
class DataConfig:
    streaming: bool = True  # ✅ По умолчанию
```

```bash
# Просто запустите обучение
python train.py
```

### Отключить Streaming (сохранить на диск)

```python
# config.py
@dataclass
class DataConfig:
    streaming: bool = False  # Данные будут сохранены локально
```

## Как это работает

```
┌─────────────────────────────────────────┐
│  Training Loop                          │
├─────────────────────────────────────────┤
│  1. DataLoader запрашивает batch        │
│  2. StreamingNPRDataset → HF dataset    │
│  3. HuggingFace подгружает изображения  │
│     из интернета по мере необходимости   │
│  4. Обработка (augmentations)           │
│  5. Передача в модель                   │
│  6. Повтор для следующего batch         │
└─────────────────────────────────────────┘

Данные НЕ сохраняются на диск!
```

## Сравнение режимов

| Параметр | Streaming | Local |
|----------|-----------|-------|
| **Место на диске** | ~0 MB | 10-20 GB |
| **Первый запуск** | Сразу | Ждать загрузку |
| **Интернет** | Нужен постоянно | Только при загрузке |
| **Скорость** | Зависит от сети | Быстрее (локально) |
| **Повторные запуски** | Тот же | Быстрее (кэш) |

## Требования

- ✅ Стабильное интернет-соединение
- ✅ Аутентификация HuggingFace (`huggingface-cli login`)
- ✅ Принятая лицензия ImageNet-1k

## Настройка производительности

```python
# config.py → TrainingConfig
training.num_workers = 4  # Количество потоков загрузки
training.pin_memory = True  # Ускорение передачи на GPU

# data/dataset.py → DataLoader
prefetch_factor=2  # Предзагрузка следующих batch'ей
```

## Ограничения

⚠️ **Streaming mode имеет некоторые ограничения:**

1. **val/test split** — в streaming mode сложно разделить данные идеально
   - Решение: использовать отдельные val/test датасеты или shuffle с разными seed
   
2. **Воспроизводимость** — порядок может отличаться при разных запусках
   - Решение: фиксированный seed через `dataset.shuffle(seed=42)`

3. **Скорость** — зависит от интернета
   - Решение: использовать локальный режим для повторных запусков

## Примеры

### Быстрый старт (Streaming)

```bash
# 1. Принять лицензию ImageNet-1k
# 2. huggingface-cli login
# 3. Запустить обучение
python train.py
```

### Локальное сохранение

```bash
# Изменить config.py: data.streaming = False
python train.py  # Данные сохранятся в data/
# Следующие запуски будут быстрее
```

### Предзагрузка данных

```bash
# Загрузить данные заранее (если нужен локальный режим)
python scripts/download_data.py --imagenet-samples 15000
```

## Переключение режимов

```python
# Streaming (по умолчанию)
config = Config()
config.data.streaming = True

# Local
config.data.streaming = False
```

## troubleshooting

| Проблема | Решение |
|----------|---------|
| **Медленная загрузка** | Увеличьте num_workers, проверьте интернет |
| **Timeout** | Уменьшите batch_size, увеличьте prefetch_factor |
| **Нет доступа к HF** | `huggingface-cli login` |
| **Dataset not found** | Примите лицензию на странице ImageNet-1k |

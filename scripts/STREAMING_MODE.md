# 🚀 Streaming Mode (fallback)

Streaming-режим подгружает данные из HuggingFace по мере необходимости,
**не занимая диск**. Это fallback для дисков с малым местом — по умолчанию
проект работает в режиме локального кэша (см. `DATA_SETUP.md`).

## Как включить

```python
# config.py
data.streaming = True
```

```bash
python train.py
```

## Требования

- Стабильное интернет-соединение на протяжении всего обучения
- Аутентификация HuggingFace (`huggingface-cli login`)
- Принятая лицензия ImageNet-1k

## Ограничения

| Параметр | Streaming | Локальный кэш |
|----------|-----------|---------------|
| Место на диске | ~0 MB | 10–20 GB |
| Скорость | Упирается в сеть и CPU-декодирование | Ограничена GPU |
| Shuffle между эпохами | Нет (фиксированный порядок take/skip) | Да |
| Длина датасета | Неизвестна (IterableDataset) | Точная |
| Повторные запуски | Тот же порядок | Шuffle каждый раз |

В streaming-режиме порядок данных фиксирован сидом (`shuffle(buffer_size=1000)`),
случайность вносит только аугментация. Для повторных запусков и тонкой настройки
гиперпараметров используйте локальный кэш.

## Настройка производительности

```python
# config.py → TrainingConfig
training.num_workers = 4   # для streaming даталодер ограничивает до 4
training.pin_memory = True # на GPU ускоряет передачу
```

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| **Медленная загрузка** | Увеличьте num_workers (до 4), проверьте сеть |
| **Timeout** | `HF_HUB_DOWNLOAD_TIMEOUT` уже поднят в data/dataset.py |
| **Нет доступа к HF** | `huggingface-cli login` |
| **Dataset not found** | Примите лицензию ImageNet-1k |
